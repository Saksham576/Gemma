# Upload kit

Files: `out/a_3am/a_3am.mp4`, `out/b_prompt/b_prompt.mp4`, `out/c_last10/c_last10.mp4`. Each is 1080×1920, 30 fps, 24 s, AAC stereo, and loops. Suggested thumbnails are `out/<short>/cover.jpg`.

For every upload:
- **Audience:** "No, it's not made for kids".
- **Altered or synthetic content:** "No" (procedural motion graphics).
- **Sound:** original, already in the file. Don't add library music.

**Post order:** `c_last10`, then `a_3am`, then `b_prompt`, one every 2–3 days, at the same time of day. The order puts the most universal dev joke first.

| Short | Title | Description |
|---|---|---|
| c_last10 | `the last 10% of every project` | `it's always DNS. #shorts #programming #developer #coding #softwareengineering` |
| a_3am | `your code at 3 AM` | `847 packages for one button. #shorts #programming #coding #javascript #devlife` |
| b_prompt | `how AI actually reads "make it pop"` | `prompt engineering is vibes. #shorts #ai #chatgpt #promptengineering #tech` |

Pin a comment that invites replies: "what's YOUR last 10%? 👇", "what time did you push to prod? 👇", "worst prompt you've ever sent? 👇".

**What to watch (Studio → Analytics → Engagement, after 48–72 h):** *Viewed vs swiped away* should be ≥ 75% viewed, and *Average % viewed* should be ≥ 70%, ideally above 100% (loops). Make the next Shorts in the format that wins. The engine makes a new one a single file in `src/shorts/`.
